# Weekly inference: Stage 4 offline implementation

**Status:** synthetic-only research code. Its command-line entry point rejects ordinary Stage 3 titles and is not connected to that pipeline; this title check is not a provenance or security guarantee. The runner does not schedule, publish, or change the website. Stage 3 has only 19 in-domain proposed merges; the previously agreed blind audit of at least 100 such merges and 95 percent precision remains open.

`scripts/media_reconstruct.py` validates twelve distinct observation manifests from the complete preceding local ISO weeks. It constructs an observer-by-story matrix, collapses repeated items from one observer to one event per local day, caps each observer at 12 distinct events daily, and takes the strongest four-week-half-life contribution per observer and event. Thus the number of posts or mirror channels cannot directly increase a cell. An inverse-document-frequency multiplier reduces the relative weight of stories attended by most modeled observers. It is a provisional weighting choice, not an empirical finding about those observers.

The solver uses seeded, non-negative multiplicative updates minimizing squared reconstruction error; its masked variant supports a held-out-cell diagnostic. It normalizes each observer's factors to fractional memberships summing to one and rejects empty rows and factors. The generated model includes all memberships, preceding-week participant shares, effective membership, story-profile similarity, and measures of held-out error, bootstrap alignment, and leave-one-observer and leave-one-brand-family sensitivity. These are algorithmic diagnostics, **not** calibrated launch thresholds. The held-out error is affected by sparsity and by which zero cells were masked; it must not be interpreted as an external forecast.

Lineage compares current and prior membership vectors with cosine similarity, preserving identities across factor permutations. A connected one-to-many relationship is a split, and a many-to-one relationship is a merger; a many-to-many ambiguity and a split/merger inheritor within 0.02 cosine similarity of another candidate fail closed for review. Births require the complete reserved-lineage ledger (including retired IDs) when a prior model exists, so a retired public letter cannot silently be reused. Both the continuity threshold of 0.65 and the ambiguity margin of 0.02 are provisional and need bootstrap calibration. The method contract also calls for a story-profile tie-breaker, but the current weekly artifact does not retain a comparable profile for each prior factor. This prototype therefore does not use one. No political labels enter either inference or lineage.

`order_decision` applies the one-standard-error rule to *supplied, measured* candidate diagnostics. It requires absolute quality gates established separately, a complete candidate-by-cutoff grid, expansion after a boundary winner, and adjacent-cutoff confirmation for a model-order change. It does **not** fabricate a 5–15 comparison from the small synthetic fixture. A full prelaunch comparison remains to be run on adequately audited data, with quality thresholds chosen and recorded beforehand.

The strict Stage 1 weekly-model and model-order validators are applied before any result is accepted. Outputs go only to ignored `.work/media-networks-stage4/`; an existing run is not overwritten. There is no production collector/clusterer-to-inference route.

For offline development, install `requirements-media.txt` separately from the site's editorial dependencies, then run `python -m unittest tests.test_media_reconstruct -v`. The normal Pages build intentionally does not install the numerical packages; it skips only these optional research tests while continuing to run the rest. The full local test suite with the packages installed exercises Stage 4.

Remaining work before Stage 4 can produce a candidate based on real observation:

1. Complete the independent Stage 3 in-domain event-identity audit. Its low external-benchmark recall (about 8.5 percent) makes it especially important to measure how many distinct co-attention events survive.
2. Establish complete panel health and missing-feed coverage for the inference window. A manifest alone cannot distinguish a silent observer from an inaccessible channel.
3. Predeclare and evaluate activity cap, common-story weighting, solver stability, sensitivity gates, and model-order thresholds on the expanded shadow panel; validate the 5–15 order search at two adjacent weekly cutoffs.
4. Review every inferred split and merger, particularly where membership shifts are caused by panel entry/exit rather than changed attention.
