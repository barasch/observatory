Private Observatory

Set up once; use your passphrase on each device. Feedback and preferences stay in your private repository.

  1. Create observatory-private. Choose Private, add a README, and use the main branch.
  2. Create a fine-grained token with access to observatory and observatory-private, and Contents: Read and write.
  3. Save the generated passphrase in your password manager. The public site stores only the encrypted token. Use a long, unique passphrase because the encrypted record is publicly downloadable.
  4. Give ChatGPT’s GitHub connection access to the private repository so the daily task can read your feedback.

These notes are private and guide future selection. Votes express interest in the material, not agreement with its conclusions. Dismissal never teaches a preference.
